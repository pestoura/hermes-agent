# BlitzHub CRA Navigator

O **BlitzHub CRA Navigator** é um produto local-first e self-service para apoiar fabricantes, importadores e distribuidores na preparação para o Cyber Resilience Act (CRA), com avaliação de âmbito, rastreabilidade regulamentar, gestão de evidências, análise de gaps e geração de relatórios.

Este repositório público é a fonte canónica do produto, da fábrica autónoma de engenharia e da respetiva governação.

## Estado

`FOUNDATION_IN_PROGRESS`

O bootstrap do runtime foi concluído e o controlo operacional foi entregue ao `blitzhub-cra-product-orchestrator`. A vaga 1 — Foundation permanece ativa até estarem concluídos e aceites o catálogo regulamentar, o schema de requisitos e rastreabilidade, a baseline arquitetural, a máquina de estados do orquestrador e a validação automática da governação.

Estado operacional atual:

- bootstrap e handoff concluídos;
- GitHub mantém-se como fonte canónica;
- Hermes executa o trabalho técnico através dos agentes da vaga 1;
- ChatGPT executa supervisão independente e publica findings, correções e relatórios através de Issues e Pull Requests;
- vagas 2 e 3 permanecem pendentes, salvo ativação parcial explicitamente aprovada e registada.

## Princípios

- GitHub como fonte de verdade.
- Hermes como executor técnico.
- ChatGPT como supervisor, corretor e promotor de melhoria contínua.
- Alterações através de branches e Pull Requests.
- Ausência de segredos, dados de clientes ou material licenciado não redistribuível.
- Resultados regulamentares rastreáveis a fontes oficiais.
- Findings `REQUIRED` impedem a conclusão do trabalho afetado.
