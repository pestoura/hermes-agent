# ADR-001 — Desktop delivery stack (reversível)

- **Status**: Accepted (temporário, para MVP)
- **Deciders**: blitzhub-cra-solution-architect
- **Date**: 2026-07-31
- **Issue**: #5 (ARCH-001)
- **Priority**: MEDIUM (reversível — ver D-01)

## Context

O produto entrega desktop Windows como primeira forma, sem exigir Docker ao utilizador
(PME). A stack de embalagem afeta packaging, signing e update, mas a arquitetura de
domínio (tzones A/B/C/D) deve permanecer independente da stack.

## Decision

Adotar **Electron** como baseline reversível para o MVP:

1. **Runtime**: Electron (processo principal Node + renderer Chromium).
2. **Packaging**: `electron-builder` → NSIS `.exe` + `.msi`, code-signed.
3. **Isolamento**: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
   no renderer; preload com IPC validado.
4. **UI**: React (compatível com a política visual `visual-assets-policy.yaml` — Lightswind
   open-source).
5. **Boundary preservado**: a API `ShellAPI` expõe apenas operações seguras ao renderer;
   a lógica de domínio não muda se a stack for trocada.

## Alternatives considered

- **A1 — Tauri (Rust)**: menor footprint, mas menos testado no Windows SME e a UI web
  reutilizável exigiria re-escrita. Mantido como alternativa v2 (D-01).
- **A2 — .NET MAUI / WinForms**: exigiria runtime Windows separado e aumenta a surface de
  privilégio. Rejeitado para o MVP.
- **A3 — App nativo PWA/ Electron sem Node main**: perde acesso a file-I/O necessário ao
  Evidence Vault. Rejeitado.
- **A4 — Docker-like bundling (rejeitado)**: violea o requisito explícito "sem Docker ao
  utilizador".

## Consequences

- **Positivo**: UI web reutilizável, cross-platform futuro, comunidade madura.
- **Negativo**: footprint maior que Tauri; dependência de Node native modules.
- **Reversível**: a boundary `shell` (contracts/05-shell-api.yaml) isola o domínio da
  stack. Swap para Tauri/.NET não toca TZ-A/B.

## Revisão

- **Gate**: v1.0-beta — validar startup time, footprint e SmartScreen na assinatura (ADR-008).
- **Owner**: desktop-packaging-engineer (w3).
